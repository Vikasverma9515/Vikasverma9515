## Cairn — an in-app AI copilot that actually clicks the buttons

Most "AI copilots" are a chatbot bolted onto the side of an app that tells
a user what to click. Cairn reads your app's real source, builds a
verified map of what's actually on each page, and lets an agent **do
it** — navigate, fill a form, click through a multi-step flow, or hold a
live voice conversation — using the app's real UI, not a hallucinated one.

```bash
npx @cairnvibe/indexer setup   # one command, wired into a real Next.js app
```

- **Verified, not trusted** — every action is checked server-side against
  a fixed schema before it runs, so a prompt-injection attempt in the
  user's question can never produce an action that wasn't explicitly
  registered.
- **Real agentic loop** — a Planner/Critic/Executor cycle drives
  multi-step goals ("find this invoice, then archive it"), not a
  single-shot prompt.
- **Live voice, not a demo trick** — streaming Deepgram STT/TTS over a
  persistent WebSocket, sub-2s response, real barge-in.
- **Published and working today** — three packages on npm
  (`@cairnvibe/core`, `@cairnvibe/sdk`, `@cairnvibe/indexer`), MIT
  licensed, framework runtime included for anything beyond React too.

[**Live demo**](https://cairn-phi-flame.vercel.app) · [**Source**](https://github.com/Vikasverma9515/cairn) · [**npm**](https://www.npmjs.com/package/@cairnvibe/sdk)
