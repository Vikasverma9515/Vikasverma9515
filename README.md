## 🪨 Cairn — an in-app AI copilot that actually clicks the buttons

<div align="center">
  <img src="https://img.shields.io/npm/v/@cairnvibe/sdk?style=for-the-badge&color=E07A3F&label=npm" />
  <img src="https://img.shields.io/npm/dw/@cairnvibe/sdk?style=for-the-badge&color=1B1815&label=downloads" />
  <img src="https://img.shields.io/github/stars/Vikasverma9515/cairn?style=for-the-badge&color=EDE6DA&label=stars" />
  <img src="https://img.shields.io/badge/license-MIT-6366f1?style=for-the-badge" />
</div>

<br>

Most "AI copilots" are a chatbot bolted onto the side of an app that
*tells* a user what to click. Cairn reads your app's real source, builds
a verified map of what's actually on each page, and lets an agent
**do it** — navigate, fill a form, click through a multi-step flow, or
hold a live voice conversation — using the app's real UI, not a
hallucinated one.

```bash
npx @cairnvibe/indexer setup   # one command, wired into a real Next.js app
```

<table>
<tr>
<td width="50%" valign="top">

**🔒 Verified, not trusted**
Every action is checked server-side against a fixed schema before it
runs — a prompt-injection attempt in the user's question can never
produce an action that wasn't explicitly registered.

**🧠 Real agentic loop**
A Planner → Critic → Executor cycle drives multi-step goals ("find this
invoice, then archive it"), not a single-shot prompt.

</td>
<td width="50%" valign="top">

**🎙️ Live voice, not a demo trick**
Streaming Deepgram STT/TTS over a persistent WebSocket, sub-2s response,
real barge-in mid-sentence.

**📦 Published and working today**
Three packages on npm, MIT licensed, a framework-agnostic Web Component
runtime for anything beyond React too.

</td>
</tr>
</table>
